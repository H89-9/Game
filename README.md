# Ночной диспетчер: Энергосеть

## 1. Описание игры

«Ночной диспетчер» — двухмерная логическая игра, разработанная на C# с использованием Windows Forms.

Игрок выступает в роли диспетчера городской электросети. После аварии часть города осталась без электричества. Задача игрока — восстановить питание зданий, правильно соединяя элементы электрической сети.

## 2. Игровой процесс

Игра состоит из нескольких уровней, сложность которых постепенно увеличивается.

На игровом поле находятся генератор электричества, провода, соединительные узлы и здания-потребители.

Игрок поворачивает участки сети, чтобы построить непрерывную цепь от генератора до необходимых зданий.

## 3. Основные механики

- Поворот элементов электрической сети.
- Передача электричества по соединённым проводам.
- Ограниченное количество ходов.
- Ограничение времени на прохождение уровня.
- Разные конфигурации игрового поля.
- Постепенное увеличение сложности.
- Проверка условий победы и поражения.

## 4. Управление

- Левая кнопка мыши — повернуть выбранный элемент сети.
- Escape — поставить игру на паузу.
- Кнопка «Заново» — перезапустить уровень.

## 5. Условия победы и поражения

**Победа:** все необходимые здания подключены к источнику электричества.

**Поражение:** закончилось время или превышено допустимое количество ходов.

## 6. Технологии

- Язык программирования: C#.
- Графический интерфейс: Windows Forms.
- Архитектура: MVC (Model-View-Controller).
- Модульное тестирование: NUnit.
- Контроль версий: Git и GitHub.

## 7. Архитектура проекта

Проект будет разделён на три основные части:

- **Model** — состояние игрового поля, правила соединения проводов, проверка победы и поражения.
- **View** — отображение игрового поля, элементов сети и интерфейса.
- **Controller** — обработка действий игрока и взаимодействие с моделью.

Игровая логика не будет зависеть от графического интерфейса. Для основных методов модели будут написаны модульные тесты.

## 8. Этапы разработки

1. Создание проекта Windows Forms.
2. Разработка модели игрового поля.
3. Отображение сетки и элементов.
4. Реализация поворота проводов.
5. Реализация распространения электричества.
6. Добавление победы, поражения и таймера.
7. Создание нескольких уровней.
8. Написание модульных тестов.
9. Финальное тестирование и оформление проекта.
