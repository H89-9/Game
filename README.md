# Ночной диспетчер: Энергосеть

Небольшая логическая игра на C# и Windows Forms (.NET 8). После аварии нужно восстановить подачу электричества от генератора к дому, поворачивая участки проводов.

## Как играть

1. На главном экране нажмите «Начать играть».
2. Выберите «Уровень 1».
3. Нажимайте левой кнопкой мыши на провод, чтобы повернуть его на 90°.
4. Соедините генератор с домом до окончания времени и ходов.

В первом уровне доступно 20 ходов и 3 минуты. Подключённые провода становятся зелёными. Генератор и дом неподвижны. Есть кнопки перезапуска и возврата к выбору уровней.

На экране выбора показано 10 уровней. **Реализован и доступен только первый.** Остальные пока заблокированы.

## Структура проекта

- `NightDispatcher` — главное меню, выбор уровней, окно игры и отрисовка (Windows Forms).
- `NightDispatcher.Core` — клетки, игровое поле, поворот проводов, распространение энергии, победа и поражение. Не зависит от Windows Forms.
- `NightDispatcher.Tests` — модульные тесты модели на NUnit.

Взаимодействие с моделью происходит через `GameController`, а `BoardView` только показывает поле и сообщает, на какую клетку нажали.

## Запуск

Откройте `NightDispatcher.sln` в Visual Studio 2022 с установленным компонентом «Разработка классических приложений .NET» и SDK .NET 8. Выберите проект `NightDispatcher` запускаемым и нажмите F5.

Для проверки тестов откройте **Тест → Обозреватель тестов → Выполнить все**. При первом запуске тестов может потребоваться восстановление пакетов NuGet.

## Управление

- Левая кнопка мыши — поворот провода.
- «Заново» — начать уровень сначала.
- «К уровням» — вернуться к выбору уровней.
